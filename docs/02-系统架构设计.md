### 1.2 技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | React 18 + TypeScript + Ant Design | 现代化UI框架，组件丰富 |
| 后端 | Python 3.11 + FastAPI | 高性能异步框架 |
| 任务队列 | Celery + Redis | 分布式任务调度 |
| 消息队列 | RabbitMQ | 可靠的消息传递 |
| 数据库 | PostgreSQL 15 | 可靠的关系型数据库 |
| 缓存 | Redis 7 | 高性能缓存 |
| 文件存储 | MinIO | S3兼容对象存储 |
| 日志 | ELK Stack | 日志收集和检索 |
| 容器 | Docker + Kubernetes | 容器化部署 |
| 监控 | Prometheus + Grafana | 系统监控 |
